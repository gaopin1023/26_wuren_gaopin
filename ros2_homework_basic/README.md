作业完成思路：
1.采用参数方程x=center_x+radius_x*sin(2*t)、 y=center_y+radius_y*sin(t)
center_x,center_y固定为turtlesim默认中心(5.544,5.544)。
radius_x, radius_y 控制8字的宽度和高度，整体控制乌龟8字半径，二者需相等
2.使用比例控制器订阅获取乌龟实时位姿，计算当前位置与期望位置的误差。同时防止乌龟速度过大前进不稳。
3.将可调参数写入yaml文件，通过launch加载。
4.启动自定义节点，自动复位乌龟到中心点，然后进入控制循环。
 
 过程中遇到的困难及解决方法：
1.看到作业遇到的第一个问题大概就是如何画出8字，我想到了双纽线，这个也可以很好解决学长提到的两圆相切问题，在询问AI可行性的时候被告知比较复杂，于是采用了它所提出的参数方程形式（补充：在此处既然提到了学长的问题，就把剩下的也在此回答了，乌龟的运动消息是geometry_msgs/Twist（表示线速度和角速度）格式，控制乌龟转向的参数为argular，其为正值则是逆时针，负值为顺时针）
2.文件夹层级混乱导致编译失败，之后查看标准目录结构之后已修正
3.一开始采取的是开2个终端，一个用来仿真小乌龟，一个用来控制其运动，后面发现较为麻烦，试了几次只能让小乌龟出现但不能运动，于是作罢，改成二合一
4.乌龟的轨迹不是很标准，同时画的8字很小，这个问题我多次调节半径和速度，但仍未解决
5.一开始总会报错说找不到文件，后面不记得为啥解决了，因为我忘记一开始的命令是啥了
6.写yaml文件时格式不太对，缩进有问题，后面改回来了
7.虽然乌龟是随机走8字，但是不知道为啥第一次和后面的有较大偏离，后面又有一些规律性，要么是8字越来越向左画，要么是位置几乎重合，现在还未解决
8.有的代码第一次运行时比较正常，第二次时乌龟会乱跑或抖动，甚至形不成完整的8字，后面减小半径和速度解决了
9.有一次乌龟出现了撞墙的情况，后面减小半径和速度解决了
