1.在本次任务中我担任四号成员，按照分工书，负责控制与感知。简单来讲，是负责接收二号的位姿信息和三好的路径规划信息，结合二者的信息，以及控制算法，对小车进行控制，让仿真小车在界面中实现九十度转弯。
2.完成情况：代码任务完成，但由于与前面两位成员的信息接收上出现问题，导致未能完成小车运动的任务。
3.代码思路：
总体来讲，代码主体要体现控制算法，同时要接收和处理信息，此外应当有便于调试的部分（比如rviz）
由于我的ROS2学习不太扎实，因此使用AI生成目录结构：
（1）路径处理类path_handler.py
解析路径点，获取坐标和航向角
计算欧式距离，通过四元数分量获取四元数
找路径上的最近点
搜索预瞄点
判断直角弯
（2）ackermann_controller.py运动学工具
体现控制算法：本次采取纯跟踪算法（最优控制效果更好，但很繁琐，纯跟踪可以实现基本功能）
控制速度：直道用快速，弯道用慢速，避免侧滑
（3）pure_pursuit_node.py ROS 主节点
加载yaml参数文件
订阅全局路径和位姿话题
下发速度指令
rviz可视化
（4）参数文件pure_pursuit_params.yaml
