Linux 基本文件管理命令
1. 目录（文件夹）操作命令
pwd：查看当前所在路径（最常用，确认自己在哪）
ls：列出目录下的文件 / 文件夹
ls -l：查看文件详细信息（权限、大小、修改时间）
ls -a：显示隐藏文件（以 . 开头的文件）
cd：切换目录
cd /：进入系统根目录
cd ~：进入当前用户家目录
cd ..：返回上一级目录
cd 文件夹名：进入指定文件夹
mkdir：创建新文件夹
例：mkdir test → 创建名为 test 的文件夹
rmdir：删除空文件夹

2. 文件操作命令
touch：创建空文件
例：touch main.cpp → 创建 cpp 空文件
cp：复制文件 / 文件夹 
例：cp test.txt ~/桌面 → 把 test.txt 复制到桌面
mv：移动文件 或 重命名
重命名：mv old.txt new.txt
移动：mv test.txt ~/文档
rm：删除文件 / 文件夹
rm 文件名：删除文件
rm -r 文件夹：递归删除文件夹
rm -rf：强制删除（慎用！不可恢复）
cat：查看文件内容
例：cat test.py → 直接显示文件全部内容

3. 辅助命令
man：查看命令帮助手册
例：man ls → 查看 ls 命令的用法

1.规定最低版本为3.19         cmake_minimum_required(VERSION 3.19)
2.设置项目名字                                 project(Test)
3.设置C++编译标准为14        set(CMAKE_CXX_STANDARD 14)      set(CMAKE_CXX_STANDARD_REQUIRED ON) 
4.导入第三方OpenCV库                   find_package               include_directories
5.添加头文件文件夹                        include_directories
6.编译静态库                                     add_library
7.生成可执行文件                             add_executable
8.绑定依赖                                         target_link_libraries
