作业一②：相比于上一个作业有固定的alpha，这里的alpha是不固定的，被称为闭环仿真。对于这个作业，我先去学习了纯跟踪算法，了解它的原理（用预瞄点搜索函数）和数学推导，一开始忘记在参数处补加Ld导致了运行报错，之后根据速度15，我将它赋值为8，最后的轨迹是比较贴合原跟踪轨迹的，但是我发现每个弯道最低点、最高点，实际轨迹会稍微向弯道外侧偏移一点，询问AI后得知：纯跟踪算法是几何前视控制，存在天然跟随滞后：车辆只有向前看到弯道才会调整转向，无法提前预判曲率变化；同时车速v=15较快，滞后效应会小幅放大。

这个作业我也进行了拓展作业的完成，然后我感觉还蛮有意思的。一开始由于车速较大，轨迹是打圈的，而且没有办法完整跟踪200米，后来发现是步数和车速的共同问题，就改成了步数3760加车速6，最后的轨迹还算正常，不过会在最后剧烈震荡，截图已放在作业里面。然后我修改了可能的因素，比如Ld,从8改成了12，发现轨迹贴合得还蛮不错的。原因： Ld=8：车辆X≈180m就只剩20m，小于两倍预瞄距离，后半段持续处于预瞄不足状态，不断剧烈修正 → 末尾打结； Ld=12：车辆直到X≈188m才会预瞄不足，剩余可行驶距离很短，很快触发 break终止仿真，没有足够步数让轨迹绕圈波动。不过还有一个问题是我感觉已经运动到200米尽头了，不过这可能是肉眼的主观判断问题。
